## 本地写作

Obsidian 直接编辑 Markdown 文件。

标题、日期和标签写在文章属性中。

## 发布链路

1. 在 Obsidian 写文章
2. 用 Git 提交并推送
3. GitHub Actions 自动构建
4. GitHub Pages 更新公网博客
