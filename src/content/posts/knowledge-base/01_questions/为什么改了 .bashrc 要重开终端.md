# 为什么改了 .bashrc 要重开终端？

## 状态

已解决（2026-10-07 想通，机制记在 [[shell 启动文件的四种读法]]）。

## 为什么现在出现

接着 [[环境变量是进程启动那一刻的复印件]] 冒出来的：`export` 写在 `~/.bashrc` 里，
手敲 `codex` 有密钥，脚本和 IDE 里却拿不到。

## 待答问题

- ❓ 同一句 `export` 分别放进 `.bashrc`、`.profile`、`.bashrc` 的守卫之前、
  以及 `BASH_ENV` 指向的文件里，四种放法各在哪种启动方式下生效？
  （四条 `env -u VAR bash -c 'echo ${VAR:-空}'` 对照跑一遍）
- ❓ IDE 插件和 cron 注入环境变量的"正规做法"是什么？
  （挑一个你能改的插件，看它是在哪一层设的环境）

## 事实

- 非交互式 shell 不读 `.bashrc`（开头那段 `case $- in *i*) ...` 守卫会直接 return），
  要投递变量得用 `BASH_ENV`。
