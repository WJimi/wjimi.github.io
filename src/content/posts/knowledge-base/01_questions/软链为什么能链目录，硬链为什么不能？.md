# 软链为什么能链目录，硬链为什么不能？

## 状态

已解决（结论在 [[一切皆文件指的是接口统一]]）。

## 为什么现在出现

为了让桌面端和 WSL 共用一套技能，想把 WSL 的 `~/.codex/skills` 变成指向 Windows 侧目录的软链。
过程中冒出两个问题：软链能不能链目录？为什么硬链不能？

## 事实

- 硬链加的是"目录项 → inode"的第二个名字，inode 里记 links 计数；目录硬链会成环，所以被禁止。
- 软链是另一个文件，内容是路径字符串，和目标是不是目录无关。
