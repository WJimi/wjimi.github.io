# Web 安全 8 周目标

## 来源

从 [[我该往哪个方向走]] 收束出来的：不再问"方向是什么"，改成"8 周交付哪几样东西"。

## 它解决的问题

8 周后拿什么判断自己确实到过某个水平？这 8 周拿什么当主线？

## 验收标准

逐条可查：

- [ ] 独立完成 PortSwigger 30–50 个 Labs
- [ ] 能写规范的漏洞报告
- [ ] 能参加 CTF Web 方向并做出简单题
- [ ] 能搭靶场、复现简单 CVE（只挑有公开 WP、环境能一键起的；卡超过两天换一个）
- [ ] 简历上有 Writeup 和项目

## 主线：PortSwigger Web Security Academy

免费在线靶场，配讲义，两百多个 lab，分 Apprentice / Practitioner / Expert 三档，每道有独立实例、
通关判定和官方解答，不用自己搭环境。它练"认出并利用某个漏洞"，平台综合题多一步"先判断在考什么"，
两条线都要走。

### 英语这关（2026-10-16 补）

lab 题面是操作说明，句式高度重复，读二十道左右基本免疫。

- 整页翻译当拐杖，术语回原文对一遍（`exploit server`、`submit solution`、`access control`、`sandbox`）。
- 读题只抓三样：目标、已知条件、不能改什么。
- 官方解答读不动，先用中文题解定位思路，再回官方解答校对。

## 行动路线

按"一个焦点 → 卡点 → 缺口 → 沉淀"排：

- **一个焦点**：PortSwigger 当缺口探测器，不按 Track 顺序啃课；卡在哪个机制就只补那一个。
- **每周一个交付物**：一篇 Writeup（`review/`）或一篇机制笔记或一个能跑的脚本。按产出记，不按小时记。
- **卡点即笔记**：卡住的题写 WP，卡住的机制写知识笔记。
- **用自己的题当发动机**：出题 → 写 WP → 固化成能一键复现的靶场，IVN 那条路继续走。

## 还没定下来的

- 数 lab 个数只量到"做过"，缺一条限时自测（纲要第 13 节四级：解释 / 使用 / 排错 / 迁移）。
- 容量没算：30–50 个 lab 加每周一篇产出，按 1–3 小时/lab 是 12–25 小时/周，要么减量要么改判定。
- "卡多久才允许看官方解答"没写，这条防线等于没有。
- "能搭靶场"和"不做装环境"冲突，要有一句让步；IVN 那套脚手架算不算已经够。
- "能做出简单题"没指定平台和难度，8 周后判不了对错。
