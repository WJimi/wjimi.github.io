前言

Claude Code 在干活时，终端会滚动一堆有趣的 …ing 状态词，官方没有公开完整列表，社区 逆向 / 扒源码整理出 187 个左右。下面按「字母序 + 场景分类」一次性整理齐全，方便你写脚本、做监控、玩梗。

#### A｜启动 / 准备 / 初始化
    Absorbing 吸收信息
    Accomplishing 完成中
    Actioning 执行动作
    Actualizing 落地实现
    Analyzing 分析中
    Architecting 架构设计
    Aligning 对齐 / 规整

#### B｜构建 / 混合 / 趣味烘焙系（很常见）
    Baking 烘焙中（经典彩蛋）
    Beaming 光束推进
    Beboppin’ 爵士摇摆（彩蛋）
    Befuddling 迷糊思考
    Blending 混合中
    Boiling 煮沸 / 高强度运算
    Brewing 酝酿中
    Building 构建项目
    Bundling 打包依赖

#### C｜计算 / 核心处理（高频）
    Calculating 计算中
    Cerebrating 深度用脑
    Channelling 集中处理
    Churning 反复搅动 / 处理
    Clauding Claude 专属彩蛋
    Coalescing 融合合并
    Cogitating 深思熟虑
    Combobulating 整理逻辑
    Compiling 编译中
    Composing 撰写 / 生成
    Compressing 压缩中
    Computing 运算中
    Concocting 构思方案
    Conjuring 变魔术式生成
    Considering 考虑中
    Contemplating 沉思
    Cooking 烹饪式处理
    Crafting 精心制作
    Creating 创建中
    Crunching 密集运算

#### D｜解析 / 解密 / 推导
    Deciphering 破译 / 解读
    Decoding 解码中
    Deliberating 斟酌中
    Determining 判定中
    Discombobulating 打乱重组
    Divining 推演预测
    Doing 干就完了（极简）

#### E｜执行 / 生效 / 评估
    Effecting 生效执行
    Evaluating 评估方案

#### F｜生成 / 锻造 / 发散
    Forging 锻造生成
    Forming 形成结构
    Frolicking 快乐摸鱼（彩蛋）

#### G｜生成 / 发芽 / 集合

    Grouping 分组归类

#### H｜孵化 / 聚集 / 趣味
    Hatching 孵化方案
    Herding 聚集整理
    Honking 嘟嘟叫（彩蛋）
    Hustling 加紧干活

#### I｜构思 / 想象 / 推理

    Imagining 想象中
    Incubating 酝酿孵化
    Inferring 推理中

#### J｜摇摆 / 爵士风彩蛋

#### M｜映射 / 匹配 / 慢思考

    Marinating 慢慢酝酿
    Matching 匹配比对
    Meandering 慢悠悠梳理
    Moseying 闲逛式思考
    Mulling 反复琢磨
    Mustering 集中资源
    Musing 沉思冥想

#### N｜归一 / 收窄 / 琢磨
    Narrowing 收窄范围
    Noodling 瞎琢磨
    Normalizing 归一化

#### O｜优化 / 组织
    Optimizing 优化中
    Organizing 组织整理

#### P｜解析 / 处理 / 打磨 / 规划
    Parsing 解析代码

    Planning 规划中
    Polishing 打磨优化
    Pondering 深思
    Pontificating 高谈阔论（彩蛋）
    Preparing 准备中
    Processing 处理中
    Programming 编程中
    Projecting 投影 / 预估
    Puttering 慢悠悠折腾
    Puzzling 解谜思考

#### Q｜ 量化 / 查询 / 排队
    Quantizing 量化中
    Querying 查询中
    Queueing 排队中

#### R｜重构 / 渲染 / 检索 / 推理

    Retrieving 检索中

    Running 运行中

    Unfurling 逐步展开
